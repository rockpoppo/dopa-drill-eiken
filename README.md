- ドパキチ・ドパドリルの名前とロゴは原作者のもので、原作ライセンス（LICENSE）の非営利ファン作品の条件にしたがって使っています。
- 「英検」は公益財団法人 日本英語検定協会の登録商標です。本作は同協会とは関係ありません。
- 単語と訳は独自に作成したものです。間違いに気づいたら Issue で教えてください。
- フォント：Dela Gothic One / Zen Maru Gothic（SIL Open Font License 1.1、OFL-*.txt 参照）
